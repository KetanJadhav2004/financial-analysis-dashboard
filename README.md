# financial-analysis-dashboard
Power BI dashboard for sales, COGS, and profit analysis

## 🔍 Overview
This project is a Power BI dashboard to analyze Sales, COGS, and Profit.

## 🛠️ Tools Used
- Microsoft Power BI

## 📊 Features
- KPI Cards (Sales, COGS, Profit)
- Country Filter (Slicer)
- Profit by Product
- Profit by Segment
- Monthly Sales vs COGS

## 📈 Insights
- Total Sales: 118.73M
- Total Profit: 16.89M
- Top Product: Paseo
- Top Segment: Government
